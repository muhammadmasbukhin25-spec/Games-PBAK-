To‑Do List aplikasi sederhana menggunakan localStorage.

File yang ditambahkan:
- todo.html — halaman aplikasi.
- todo.css — gaya tampilan.
- todo.js — logika aplikasi (tambah, edit, hapus, tandai selesai, persistence).

Cara menjalankan:
1. Buka `todo.html` di browser.
2. Tambahkan tugas di input, tekan "Tambah" atau Enter.
3. Klik checkbox untuk menandai selesai. Gunakan tombol Hapus atau tombol 🗑️ untuk menghapus tugas.

Fitur:
- Persisten: tugas disimpan di localStorage (kunci: `todo.tasks.v1`).
- Edit: klik dua kali pada teks tugas atau tekan tombol ✏️.
- Hapus semua atau hapus hanya tugas yang selesai.
