*Tic-Tac-Toe sederhana untuk tugas PBAK.*

Cara menjalankan:
1. Buka file `index.html` di browser (double-click atau `Open File`).
2. Centang "Main lawan komputer" untuk bermain melawan komputer (komputer memilih langkah secara acak).
3. Klik kotak untuk menaruh X/O. Tekan tombol "Mulai Ulang" untuk memulai ulang permainan.

Saran pengembangan:
- Tambahkan AI lebih pintar (Minimax).
- Tambahkan skor dan mode online.
